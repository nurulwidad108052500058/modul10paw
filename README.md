## About Laravel

Laravel is a web application framework with expressive, elegant syntax. It makes web development easier with features such as routing, controllers, views, and database management.

## Project Features

- Home Page
- Profile Page
- Employee List
- Create Employee
- Form Validation
- CSRF Protection
- Displaying Validation Errors
- Repopulating Forms

## How to Run

1. Install project dependencies using `composer install`.
2. Copy `.env.example` to `.env`.
3. Generate application key using `php artisan key:generate`.
4. Install frontend dependencies using `npm install`.
5. Run the Laravel server using `php artisan serve`.
6. Run Vite using `npm run dev`.
